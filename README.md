# Muzi To-Do 📱

Ein minimalistisches, hochgradig ästhetisches To-Do-Erlebnis im runden **Android Mobile UI Design** (Schwarz-Weiß).

## ✨ Features

- **🖤🤍 Pures Schwarz & Weiß (OLED-optimiert):** Konsequentes Monochrom-Design mit abgerundeten Ecken und feinen Konturen.
- **📱 Android Smartphone Frame:** Google Pixel Gehäuse mit Frontkamera-Aussparung, Live-Uhrzeit in der Statusleiste und Gestenleiste.
- **✨ Ästhetischer Willkommens-Bildschirm:** Typografischer Einstieg („Fokus auf das Wesentliche.“) mit sanften Reveal-Animationen.
- **👉 Wischgeste zum Löschen:** Aufgaben können per Finger- oder Mauswisch nach rechts intuitiv gelöscht werden.
- **⌨️ Smarte Android-Tastatur:** Beim Antippen des Eingabefeldes fährt die Zeile geschmeidig nach oben und macht Platz für die Tastatur.
- **🌓 Schneller Hell-/Dunkelmodus:** Runder Umschalter mit sanfter Sonnen- und Mond-Rotationsanimation ohne jegliche Verzögerung.
- **📊 Fortschrittsanzeige:** Gestaffelte Statistik mit fließendem Schimmer-Effekt und Filterung nach *Offen*, *Erledigt* und *Alle*.
- **💾 Lokale Persistenz:** Aufgaben und Erscheinungsbild werden zuverlässig im Browser (`localStorage`) gespeichert.

---

## 🚀 Schnellstart

Einfach die Datei `index.html` in einem modernen Webbrowser (Chrome, Edge, Firefox, Safari) öffnen. Es ist kein Build-Schritt oder Server erforderlich!

```bash
# Repository klonen
git clone https://github.com/SadBoy17590274/Muzi-To-Do.git

# In das Verzeichnis wechseln
cd Muzi-To-Do

# index.html direkt starten
start index.html
```

## 🛠️ Technologien

- **HTML5:** Semantische Struktur und Barrierefreiheit.
- **CSS3:** Custom Properties, CSS Grid, Flexbox, Hardware-beschleunigte Keyframe-Animationen & Cubic-Bezier-Kurven.
- **JavaScript (ES6+):** Vanilla JavaScript ohne externe Abhängigkeiten, reaktives State Management und Touch-/Pointer-Gesten.
